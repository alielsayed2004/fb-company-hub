# F.B Company — Official Resources & Links Hub

A centralized institutional portal for F.B Company's official Google Sheets, administrative resources, contact channels, and social media links.

## Tech Stack
- **Framework:** React 19 + TypeScript + Vite 8
- **Styling:** Tailwind CSS v4
- **Icons:** Lucide React
- **Linter:** Oxlint

## Getting Started

```bash
# Install dependencies
npm install

# Start development server
npm run dev

# Build for production
npm run build
```
